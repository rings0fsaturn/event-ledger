# Work Record

- `.work/` is persistent working memory across sessions.
- Keep `.work/STATUS.md`, task state, and session notes current as work lands.
- Use `work-journal-orchestrator` for work-record changes rather than editing those files directly.
- `.work/spec/event-ledger.md` is the task contract: invariants, locking, determinism, proof obligations, load/chaos, environments/cost, DDIA mapping, and glossary.
- `/mnt/d/study/BOOKS/Designing-Data-Intensive-Applications.pdf` is the DDIA reference used by the spec.
- `.work/README.md` defines the work-record structure and ownership.
