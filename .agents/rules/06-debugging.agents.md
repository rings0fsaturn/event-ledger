# Debugging

- Debugging is investigation, not authorship.
- The agent may inspect logs, traces, query plans, tests, configuration, call paths, and runtime behavior freely.
- First identify the actual failure and its cause; do not guess from the symptom alone.
- Explain the cause in simple words with a small example when useful.
- State the fix precisely: what changes, where it changes, why, and how to verify it.
- The author writes the application/configuration fix unless explicitly asked otherwise.
- Do not hand over a ready-made diff when the learning goal is understanding the fix.
