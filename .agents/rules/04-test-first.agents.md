# Test First

- Core mechanisms are defined by tests before implementation.
- The agent writes tests from the specification; the author writes the implementation.
- A failing test is information, not an obstacle.
- Keep the test failing until the author's implementation satisfies it.
- Use tests as the precise target for guards, dedupe, reservations, projections, sweepers, and similar logic.
- Explain what behavior each test proves and why that behavior matters.
- Do not use tests as a substitute for explaining the underlying concept.
