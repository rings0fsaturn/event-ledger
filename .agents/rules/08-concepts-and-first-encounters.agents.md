# Concepts and First Encounters

- Every core concept must be explainable aloud with an example.
- Important concepts include concurrency/isolation, write skew, lost updates, phantom reads, idempotency, effectively-once, exactly-once boundaries, deterministic replay, projections, lag, and backpressure.
- For unfamiliar tools, start with the problem they solve and their mental model before configuration details.
- First encounters include Kafka, Kubernetes, Terraform, Stripe webhooks, WSL2, and Postgres isolation.
- Prefer one concrete scenario over a long theoretical explanation.
- Depth follows the author's question; do not turn a simple question into a lecture.
