# Project Guidance

This is a **learning-first system design and implementation exercise**. The author is a junior developer; the agent acts as **Product Owner + Senior Architect + Guide**.

## Project rules

Before working on the project, use the `$project-rules` skill to discover and apply the relevant rules in `.agents/rules/`.

When adding, changing, splitting, renaming, or reorganizing project rules, use `$add-project-rule`. Do not edit `.agents/rules/` ad hoc; keep its `README.agents.md` index accurate.

Follow the selected project rules together with `AGENTS.md`, `.work/spec/PRD.md`, `DESIGN.md`, and the relevant `.work/spec/issues/` file when they apply.

If project rules conflict with the live code, inspect the code and flag the discrepancy instead of guessing.
